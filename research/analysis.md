# 京大物理から取り出す、誘導型演習の構成

調査日：2026-11-20。対象は学部一般選抜の前期物理。年度の大分類42年分と、代表例の構造読解を区別した初版調査である。

## どこまで確認したか

| 範囲 | 確認したもの | 確認していないもの |
| --- | --- | --- |
| 1985〜2022（38年度） | 伊達の物理の年度別大分類 | 全年度の原本、空欄数、設問の全依存関係 |
| 2007〜2016（上記と重複する10年度） | 東進の大問別細目 | 原本の逐語的な分析 |
| 1990 I、1995 I、1997 I、2000 III、2005 I | 第三者サイトの再掲問題文 | 大学の原本との照合 |
| 2023・2024 | Z会による大問別講評 | 全問題文の精読 |
| 2025・2026 | 大学公式の全3大問の出題意図 | 全設問の独立解答・図を含む全原本精読 |

したがって「42年の全問題を精読した」という結果ではない。大問の大分類は [年度別索引](year-index.md)、追跡できる出典は [出典台帳](sources.json) に記録した。各年度の詳細調査を今後そのまま追記できる。

## 観察できた形式と修正点

近年の3題構成は公式資料で確認できる。一方、年度一覧では1987年に4題、1995・2001・2006年には力学が独立した大問として載っていない。3題の順序も、常に力学・電磁気・第三分野というわけではない。[年度一覧](https://date-physics.jimdofree.com/入試解説/京都大/)、[2025問題表紙](https://www.kyoto-u.ac.jp/sites/default/files/inline-files/admissionsundergradpast_eqR07_eqdocumentsR07_4M102-e9a205ea41f89c539dad05f16fa904f2.pdf)

第三分野には熱・波動・原子がある。「原子」は原子力に限らず、光や原子模型などを含む。細目は複数分野にまたがるため、主分野のラベルだけで教材の構成を決めない。[2007〜2016の細目](https://www.toshin-daigaku.com/inc_univ/042/pdf/6_kyodai_butsuri.pdf)

文章中の空欄は、別々の小問集合というより一つの設定を進める途中結果として働く。記述や作図が途中に入る場合もあり、最後が必ず独立の大記述という決まりは確認できない。再掲された1990・1997・2005の例は、空欄を連ねて結論に進む構成である。

## 高校単元と作問操作を分ける

| 分野 | 確認例の単元 | 再利用できる操作 |
| --- | --- | --- |
| 力学 | 保存則、相対運動、円運動、単振動、慣性力、万有引力 | 座標を変える、保存量を選ぶ、小さく変化させる |
| 電磁気 | 電場・電位、容量、荷電粒子、電磁誘導、交流・過渡、磁場中の力 | 基本量を定義し、仕事・エネルギーに接続する |
| 熱 | 分子運動、状態方程式、第一法則、断熱・等温、サイクル | 同じ状態から別過程を比較する、符号を解釈する |
| 波動 | 共鳴、干渉、回折、偏光、全反射 | 位相・幾何条件を式にして、観測量へ戻す |
| 原子 | 原子模型、光電効果、スペクトルに関わる題材 | 未知の設定を説明し、既知の保存則や式で追わせる |

これは各単元の網羅的な出題頻度表ではない。大分類と複合分野を含む細目の粒度が異なるため、細目の出題頻度は数値化していない。東進PDFではテキスト抽出による行のずれがあったが、紙面画像で2007・2009・2010の対応を修正した。

## 作問へ移すエッセンス（設計上の推論）

1. **結論から逆算する。** 何を理解して終わるかを決め、中間結果に空欄を置く。
2. **場面を保つ。** 単語問題を連ねず、一つの関数・分布・装置について考え続ける。
3. **未知の道具は本文で与える。** 問うのは丸暗記だけでなく、定義の読み方と使い方。
4. **前の結果を次の資源にする。** 計算した数や式が後の判断を簡単にする構成にする。
5. **条件を一つ変える。** 測度、観測情報、座標、領域、近似条件などを変えて比較する。
6. **計算から意味へ戻る。** 最後は「なぜ」「何が違う」「どこで仮定を使った」を短く説明する。

15〜25分・4〜7空欄という大きさ、定義カード、段階ヒント、自己評価は、入試からの事実ではなく基礎学習用の独自設計。大問数は固定せず、初版では測度4・確率3・情報幾何3・複素4・力学3に分けた。大学数学・物理の初歩に対応する独自設定であり、京大問題を大学用語に置換したものではない。
