# 小さな誘導の設計

## 設計の順序

1. **到達点**：「積分の交換には条件が要る」「条件付き期待値は情報に応じた関数」など、説明できるようになる対象を一つにする。
2. **具体物**：単関数、四点の確率空間、ベルヌーイ族、円周積分、調和振動子など、計算と定義が同時に見える設定を選ぶ。
3. **依存する中間結果**：例として I01 は二つのスコア値 → 平均0と二乗平均 → Fisher情報 → 局所計量の比較。全空欄を機械的な直列依存にしない。並行して求める結果もある。
4. **空欄の役割**：定義の読み取り、具体計算、前結果の再利用、条件の確認、結論。全てを最初から難しくせず、手を動かせる入口を作る。
5. **最後の問い**：別条件との比較、誤解の訂正、短い理由の記述。基礎編では高難度の証明を追加しない。
6. **解説**：答え・理由・何を使ったかを分ける。記述には2〜3個の具体的な採点観点を付け、同値な表現を認める。

## 構造の変換例

京大物理の代表例で観察した「基本法則 → 設定を少し変える → 既出の量を再利用」の構造は、次のように大学数学へ移せる。

| 構造 | 基礎数学での例 | 学習負荷の調整 |
| --- | --- | --- |
| 同一設定を保つ | 一つの単関数を積分し、一点だけ変更する | 測度の変更を最後の短問にする |
| 観測視点を変える | σ-加法族を粗くして条件付き期待値を求める | 有限集合で計算してから一般定義を確認 |
| 前結果を再利用 | スコアからFisher情報を得てKLの曲率と比較する | I01とI02に分けて長大化を防ぐ |
| 適用条件を変える | 円内・円外・円周上の極を比較する | 主値積分は導入せず適用不可で止める |
| 近似と厳密式を区別 | 振り子のsinθをθに置換する | 置換箇所を言語化して終える |

## 内容の確認

- 測度：定義域と集合族。零集合はどの測度についてか。優収束では全nに共通の可積分な優関数。
- 確率：Xと分布を区別。密度の値と点の確率を区別。条件付き期待値は全ての観測可能事象上の積分を保つ。
- 情報幾何：θを(0,1)内に固定。期待値の分布を指定。KLは一般に非対称。局所二次展開を大域的距離と呼ばない。
- 複素解析：実偏微分の連続性など十分条件。曲線の向き。特異点の位置。Laurent展開の収束領域。
- 力学：座標と速度を独立に偏微分。一般化運動量と速度を区別。定数と時間変数を区別。近似条件を明記。

## 分割の判断

1つの結論を出した後に新しい定理・新しい場面・長い証明が必要なら次の大問にする。大問数の少なさや入試の制限時間を優先しない。分割先には前提IDと必要な式を示し、復習で単独に開いても立ち止まらないようにする。
