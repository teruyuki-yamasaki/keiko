## 問題Ⅰ　統計モデルとフィッシャー情報計量

次の文章を読んで、【　】に適した式・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) n 個の実パラメータ ξ = (ξ¹, …, ξⁿ) で滑らかに指定される確率分布の族 S = {p(x; ξ)} を統計モデルという。ξ を座標とみなせば、S は n 次元の多様体になる。各点 ξ で、対数尤度の偏微分 ∂ᵢl をスコア関数という。∫ p(x; ξ) dx = 1 の両辺を ξⁱ で微分すると

```math
E[\partial_i l] = \int \partial_i p(x;\xi)\, dx = \text{【ア】}
```

となり、スコアの平均は 0 である。そこで、スコアの共分散

```math
g_{ij}(\xi) = E[\partial_i l\; \partial_j l]
```

をフィッシャー情報行列という。任意の実数 c₁, …, cₙ に対し Σ cᵢcⱼgᵢⱼ = E\[(Σ cᵢ∂ᵢl)²\] ≥ 0 なので g は半正定値であり、スコアが一次独立なら正定値になる。こうして g は S 上のリーマン計量（フィッシャー計量）を定める。

また、∂ᵢ∂ⱼl = (∂ᵢ∂ⱼp)/p − ∂ᵢl ∂ⱼl と E\[(∂ᵢ∂ⱼp)/p\] = 【イ】 から、gᵢⱼ = −E\[∂ᵢ∂ⱼl\] とも書ける（問1）。対数尤度の「山のとがり具合」の平均がフィッシャー情報である。

(2) 具体例を計算しよう。

- ベルヌーイ分布 p(x; θ) = θˣ(1 − θ)¹⁻ˣ（x = 0, 1、0 < θ < 1）では ∂l = (x − θ)/(θ(1 − θ)) なので g(θ) = 【ウ】
- 分散 σ² が既知の正規分布 N(μ, σ²) では g(μ) = 【エ】
- 平均・標準偏差の両方を座標とする正規分布族 (μ, σ) では g = diag(1/σ², 【オ】)

ベルヌーイの例では θ が 0 や 1 に近いほど g が大きい。θ = 0.01 と 0.02 は、θ = 0.50 と 0.51 よりも、データから見分けやすいからである。

(3) 座標を ξ から ζ に取り替えると、フィッシャー情報は

```math
\tilde g_{ab}(\zeta) = \sum_{i,j} \frac{\partial \xi^i}{\partial \zeta^a} \frac{\partial \xi^j}{\partial \zeta^b}\, g_{ij}(\xi)
```

と、リーマン計量と同じ規則で変換される。ベルヌーイ分布で θ = sin²ϕ（0 < ϕ < π/2）とおくと g̃(ϕ) = 【カ】 と定数になる。したがってベルヌーイ族全体は長さ 【キ】 の線分と等長である。

より一般に、k + 1 個の値をとる離散分布全体（確率単体）のフィッシャー計量は ds² = Σ (dpᵢ)²/pᵢ = 4 Σ (d√pᵢ)² と書けるので、yᵢ = √pᵢ と変換すれば Σ yᵢ² = 1 を満たす単位球面の一部に4倍の計量を入れたもの、すなわち半径 【ク】 の球面の一部と等長になる。

フィッシャー計量は、十分統計量による変換（情報を失わないデータの要約）で不変である。この性質について、チェンツォフの定理によれば、十分統計量による変換で不変な確率単体上のリーマン計量は { ケ }。

- ① 定数倍を除いてフィッシャー計量に限る
- ② 無数に存在する
- ③ 存在しない

問1　gᵢⱼ = −E\[∂ᵢ∂ⱼl\] を導け。

問2　ポアソン分布 p(x; λ) = e^(−λ) λˣ/x!（x = 0, 1, 2, …）のフィッシャー情報 g(λ) を求めよ。また、λ = ν² と座標変換すると計量が定数になることを示せ。

## 問題Ⅱ　KLダイバージェンスと f-ダイバージェンス

次の文章を読んで、【　】に適した式・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 2つの確率分布 p, q の「隔たり」を測る量として、カルバック＝ライブラー（KL）ダイバージェンス

```math
D(p \,\|\, q) = \int p(x) \log \frac{p(x)}{q(x)}\, dx
```

が基本的である。不等式 log t ≤ t − 1（等号は t = 1）を t = q/p に使うと、−D(p‖q) = ∫ p log(q/p) dx ≤ ∫ p (q/p − 1) dx = 【イ】 となり、D(p‖q) ≥ 0 が従う（ギブスの不等式）。等号は p = q のときに限る。ただし一般に D(p‖q) ≠ D(q‖p) であり、KL ダイバージェンスは { ロ }。

- ① 非対称で、三角不等式も一般には満たさないので、距離ではない
- ② 対称だが、三角不等式を満たさない
- ③ 距離の公理をすべて満たす

(2) 距離ではないが、近い2点の間では KL ダイバージェンスはフィッシャー計量と結びつく。統計モデル上の2点 ξ, ξ′ について f(ξ′) = D(p(·; ξ) ‖ p(·; ξ′)) とおくと f(ξ) = 0 である。ξ′ で微分すると ∂f/∂ξ′ⁱ = −E\[∂ᵢl(x; ξ′)\]（期待値は p(x; ξ) に関する）なので、ξ′ = ξ では 【ハ】 となる。さらにもう1回微分して ξ′ = ξ とおくと −E\[∂ᵢ∂ⱼl\] = 【ニ】 となるから

```math
D\big(p_\xi \,\|\, p_{\xi + d\xi}\big) = \frac{1}{2} \sum_{i,j} g_{ij}(\xi)\, d\xi^i d\xi^j + O(|d\xi|^3)
```

を得る。KL ダイバージェンスは、局所的にはフィッシャー計量で測った距離の2乗の半分である。

例として、分散が共通の正規分布では D(N(μ₁, σ²) ‖ N(μ₂, σ²)) = 【ホ】 と正確に計算でき、問題Ⅰの g(μ) = 1/σ² と整合する。ポアソン分布では D(Po(λ₁) ‖ Po(λ₂)) = 【ヘ】 であり、λ₂ = λ₁ + dλ と展開すると D ≈ (1/2)(【ト】)dλ² となる。

(3) 凸関数 f（f(1) = 0）を用いて

```math
D_f(p \,\|\, q) = \int p(x)\, f\!\left(\frac{q(x)}{p(x)}\right) dx
```

と定めたものを f-ダイバージェンスという。イェンセンの不等式から D\_f ≥ 0 である。いくつかの例をあげる。

| 名前 | f(t) | f″(1) |
| --- | --- | --- |
| KL ダイバージェンス D(p‖q) | 【チ】 | 【リ】 |
| 逆向き KL D(q‖p) | t log t | 1 |
| ヘリンジャー距離の2乗 ∫(√p − √q)² dx | (√t − 1)² | 【ヌ】 |
| 全変動距離 | \|t − 1\|/2 | 定義されない（t = 1 で微分不可能） |

f が t = 1 で2回微分可能なら、(2) と同様の計算で、近い2点 ξ と ξ + dξ の間の f-ダイバージェンスは (f″(1)/2) Σ gᵢⱼ dξⁱ dξʲ で近似される。どの滑らかな f-ダイバージェンスも、局所的にはフィッシャー計量の定数倍に帰着するのである。

f-ダイバージェンスは、データを統計量 T で変換すると増えない（データ処理不等式 D\_f(p∘T⁻¹ ‖ q∘T⁻¹) ≤ D\_f(p‖q)）。T が十分統計量なら等号が成り立つ。問題Ⅰで述べたフィッシャー計量の不変性は、この性質の局所版である。

問1　ギブスの不等式 D(p‖q) ≥ 0 を、等号成立条件も含めて示せ。

問2　D(N(μ₁, σ²) ‖ N(μ₂, σ²)) を直接計算して【ホ】を確かめよ。

## 問題Ⅲ　指数型分布族と双対座標

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 統計量 F₁(x), …, Fₙ(x) とパラメータ θ = (θ¹, …, θⁿ) を用いて

```math
p(x;\theta) = \exp\Big( \sum_{i=1}^{n} \theta^i F_i(x) - \psi(\theta) \Big), \qquad \psi(\theta) = \log \int \exp\Big( \sum_i \theta^i F_i(x) \Big) dx
```

と書ける分布の族を指数型分布族、θ を自然パラメータ（θ 座標）という（積分は基準となる測度に関するものとする）。ψ は確率の総和を 1 にする正規化項で、対数分配関数あるいはキュムラント母関数と呼ばれる。

ψ を微分すると ∂ᵢψ = E\[Fᵢ\]、∂ᵢ∂ⱼψ = Cov(Fᵢ, Fⱼ) となる（問1）。一方、対数尤度 l = Σ θⁱFᵢ − ψ(θ) の2階微分は ∂ᵢ∂ⱼl = −∂ᵢ∂ⱼψ で x によらないので、問題Ⅰより Cov(Fᵢ, Fⱼ) = 【あ】 が成り立つ。共分散行列は半正定値なので、ψ は凸関数である。

(2) ベルヌーイ分布は p(x) = exp(θx − ψ(θ))、θ = log(p/(1 − p))（ロジット）と書けて、ψ(θ) = 【い】 である。期待値は η = ψ′(θ) = 【う】 となり、これは成功確率 p そのものである。θ 座標でのフィッシャー情報は g(θ) = ψ″(θ) = 【え】 である。問題Ⅰで求めた p 座標での値 1/(p(1 − p)) と見かけは異なるが、(dp/dθ)² = (p(1 − p))² を掛ければ一致し、座標変換則と整合している。

正規分布 N(μ, σ²) は F₁ = x、F₂ = x² として指数型分布族になり、θ¹ = μ/σ²、θ² = 【お】 である。対応する期待値は η₁ = E\[x\] = μ、η₂ = E\[x²\] = 【か】 である。

(3) ηᵢ = ∂ᵢψ(θ) で定まる η = (η₁, …, ηₙ) を期待値パラメータ（η 座標）という。ψ が狭義凸なら θ ↦ η は1対1なので、η も座標になる。θ と η を結ぶのがルジャンドル変換である。

```math
\varphi(\eta) = \sup_{\theta} \big\{ \theta \cdot \eta - \psi(\theta) \big\}
```

上限は ∇ψ(θ) = η を満たす θ で達成され、φ(η) = θ · η − ψ(θ) = E\[l\] となる。つまり φ(η) は分布の 【き】 に等しい。対応する点では ψ(θ) + φ(η) − θ · η = 【く】 が成り立ち、さらに θⁱ = ∂φ/∂ηᵢ と、逆向きの関係も同じ形で成り立つ。ヤコビ行列 ∂ηᵢ/∂θʲ = gᵢⱼ と ∂θⁱ/∂ηⱼ は互いに逆行列であり、η 座標でのフィッシャー計量は ψ のヘッセ行列の逆行列、すなわち φ のヘッセ行列になる。ベルヌーイ分布では φ(η) = 【け】 である。

こうして指数型分布族には、凸関数 ψ と φ に支えられた2つの座標 θ, η が備わる。この双対構造が以降の大問の主役である。最初の応用として、データ x₁, …, x\_N から θ を最尤推定すると、推定値 θ̂ は { こ }。

- ① 統計量の標本平均と期待値パラメータが一致する条件 η(θ̂) = (1/N) Σₖ F(xₖ) で決まる
- ② 尤度方程式に解をもたないので数値的にしか求まらない
- ③ 統計量の標本中央値で決まる

問1　∂ᵢψ = E\[Fᵢ\] と ∂ᵢ∂ⱼψ = Cov(Fᵢ, Fⱼ) を示せ。

問2　ポアソン分布を指数型分布族として表し、θ, ψ(θ), η, θ 座標でのフィッシャー情報、φ(η) を求めよ。

## 問題Ⅳ　α-接続と双対接続

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 多様体上で「まっすぐ」を決めるのがアファイン接続 ∇ である。座標基底に対する係数 Γᵢⱼ,ₖ = ⟨∇(∂ᵢ) ∂ⱼ, ∂ₖ⟩（⟨ , ⟩ はフィッシャー計量）で接続を表す。微分幾何学で学んだレヴィ＝チヴィタ接続はその一つにすぎず、統計モデルには実数 α でパラメータ付けされた接続の族（α-接続）が自然に備わっている。

```math
\Gamma^{(\alpha)}_{ij,k} = E\Big[ \Big( \partial_i \partial_j l + \frac{1 - \alpha}{2}\, \partial_i l\, \partial_j l \Big) \partial_k l \Big], \qquad T_{ijk} = E[\partial_i l\, \partial_j l\, \partial_k l]
```

α = 1 を e-接続（指数接続）、α = −1 を m-接続（混合接続）、α = 0 をレヴィ＝チヴィタ接続という。3階対称テンソル T を用いると Γ^(α)ᵢⱼ,ₖ = Γ^(0)ᵢⱼ,ₖ − 【ア】 Tᵢⱼₖ と書け、α-接続はレヴィ＝チヴィタ接続を T の方向にずらしたものである。

α-接続の間には次の関係がある。

```math
\partial_k g_{ij} = \Gamma^{(\alpha)}_{ki,j} + \Gamma^{(\text{【イ】})}_{kj,i}
```

これは「ベクトル X を ∇ で、Y を ∇\* で平行移動すると内積 ⟨X, Y⟩ が保たれる」ことを意味し、この関係にある ∇ と ∇\* を互いに双対な接続という。とくに e-接続と m-接続は双対である。自分自身と双対になるのは α = 【ウ】 のときだけで、これは計量を保つレヴィ＝チヴィタ接続の性質そのものである。

(2) 指数型分布族を θ 座標で表すと ∂ᵢ∂ⱼl = −∂ᵢ∂ⱼψ は x によらないので、E\[∂ₖl\] = 0 から Γ^(e)ᵢⱼ,ₖ = 【エ】 となる。すなわち θ 座標が e-接続の直線座標（アファイン座標）であり、指数型分布族は e-平坦である。一方、分布 p₀, p₁, …, pₙ の混合

```math
p(x;\eta) = \sum_{i=1}^{n} \eta_i\, p_i(x) + \Big(1 - \sum_{i=1}^{n} \eta_i\Big) p_0(x)
```

からなる混合型分布族では ∂ᵢ∂ⱼp = 0 であり、Γ^(m)ᵢⱼ,ₖ = ∫ ∂ᵢ∂ⱼp ∂ₖl dx = 【オ】 となるので m-平坦である。双対な接続の一方の曲率が 0 なら、他方の曲率も 0 になることが知られており、指数型分布族は e-接続に関しても m-接続に関しても 【カ】 である。m-接続の直線座標は η 座標である。

(3) 2つの分布 p, q を結ぶ測地線を書き下そう。

- m-測地線：p(t) = 【キ】（0 ≤ t ≤ 1）。確率を足し合わせる「混合」の直線
- e-測地線：log p(t) = (1 − t) log p + t log q − c(t)。対数をとってから足し合わせる「幾何平均」の直線で、正規化定数は c(t) = 【ク】

同じ2点を結んでいても、2本の測地線は一般に異なる曲線である。

(4) ベルヌーイ分布の θ 座標では、T は ψ の3階微分に等しく T = ψ‴(θ) = 【ケ】 である。p = 1/2 では T = 0 となり、この点では α によらず接続が一致する。

なお、指数型分布族は e-接続・m-接続に関して平坦だが、レヴィ＝チヴィタ接続に関しては { コ }。

- ① 一般には平坦でない（問題Ⅷの正規分布族が例）
- ② 常に平坦である
- ③ 接続そのものが定義できない

問1　e-接続と m-接続について、∂ₖgᵢⱼ = Γ^(e)ₖᵢ,ⱼ + Γ^(m)ₖⱼ,ᵢ を直接計算で確かめよ。

問2　N(μ₁, 1) と N(μ₂, 1) を結ぶ e-測地線上の分布が、すべて分散 1 の正規分布 N((1 − t)μ₁ + tμ₂, 1) になることを示せ。

## 問題Ⅴ　双対平坦空間と拡張ピタゴラスの定理

次の文章を読んで、【　】に適した式・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 問題Ⅲ・Ⅳで見た構造を抽象化する。多様体 M 上に、互いに双対な接続 ∇, ∇\* がともに平坦で、∇ の直線座標 θ と ∇\* の直線座標 η が、凸関数 ψ(θ), φ(η) を用いて η = ∇ψ(θ)、θ = ∇φ(η)、ψ(θ) + φ(η) − θ · η = 0 で結ばれているとき、M を双対平坦空間という。指数型分布族はその典型例である。

2点 P, Q（座標をそれぞれ θ\_P, η\_P などと書く）に対し、正準ダイバージェンスを

```math
D[P:Q] = \psi(\theta_P) + \varphi(\eta_Q) - \theta_P \cdot \eta_Q
```

で定める。指数型分布族でこれを計算すると、分布 q（点 Q）から分布 p（点 P）への KL ダイバージェンスと一致し、D\[P:Q\] = 【イ】 となる（引数の順序が逆になることに注意）。

φ(η\_Q) = θ\_Q · η\_Q − ψ(θ\_Q) と η\_Q = ∇ψ(θ\_Q) を代入すると

```math
D[P:Q] = \psi(\theta_P) - \psi(\theta_Q) - \text{【ロ】}
```

と書き直せる。これは「関数 ψ と、点 θ\_Q での接平面（1次近似）との高さの差」であり、ブレグマン・ダイバージェンスと呼ばれる。ψ の 【ハ】 から D\[P:Q\] ≥ 0 であり、等号は P = Q のときに限る（問2）。たとえば ψ(θ) = |θ|²/2（分散 1 の正規分布の平均パラメータ）なら η = θ で、D\[P:Q\] = 【ニ】 となり、通常のユークリッド距離の2乗の半分に一致する。

(2) 3点 P, Q, R に対し、定義に代入して整理すると

```math
D[P:R] = D[P:Q] + D[Q:R] - \text{【ホ】}
```

という「余弦定理」が成り立つ（問1）。最後の項は、Q から P へ向かう ∇-測地線（θ 座標で直線）の方向 θ\_P − θ\_Q と、Q から R へ向かう ∇\*-測地線（η 座標で直線）の方向 η\_R − η\_Q の内積である。一般に、接ベクトル X を θ 座標の成分 Xⁱ で、Y を η 座標の成分 Yᵢ で表すと、フィッシャー計量による内積は ⟨X, Y⟩ = 【ヘ】 と、計量を介さず単純な和になる。双対座標の最大の利点である。

したがって、Q において ∇-測地線 QP と ∇\*-測地線 QR が直交すれば、D\[P:R\] = D\[P:Q\] + D\[Q:R\] が成り立つ。これを拡張ピタゴラスの定理という。KL ダイバージェンスの言葉に直すと、e-測地線 QP と m-測地線 QR が Q で直交するとき

```math
D(r \,\|\, p) = D(q \,\|\, p) + \text{【ト】}
```

が成り立つ（p, q, r はそれぞれ点 P, Q, R の分布）。この定理は、次の問題Ⅵで「最も近い点への射影」を特徴づける基礎になる。

なお、ダイバージェンスの引数を入れ替えた D\[Q:P\] は、一般に { チ }。

- ① D\[P:Q\] と異なり、入れ替えると ∇ と ∇\*（θ と η、ψ と φ）の役割が入れ替わる
- ② 常に D\[P:Q\] に等しい
- ③ 負の値をとりうる

問2　ψ が狭義凸のとき、ブレグマン・ダイバージェンスが非負で、0 になるのは θ\_P = θ\_Q のときに限ることを示せ。

## 問題Ⅵ　射影定理・最尤推定・最大エントロピー・em アルゴリズム

次の文章を読んで、【　】に適した式・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。以下、標本空間は有限集合とする。

(1) データ x₁, …, x\_N が得られたとき、各値の出現割合を確率とする経験分布 p̂ を考える。モデル M = {p(x; θ)} の分布との KL ダイバージェンスは

```math
D(\hat p \,\|\, p_\theta) = \sum_x \hat p(x) \log \hat p(x) - \text{【あ】}
```

と書ける。第1項は θ によらないので、D(p̂‖p\_θ) を最小にする θ は最尤推定量に一致する。最尤推定は、データ点 p̂ からモデル M への「最も近い点」探しである。

M 上の点 q のうち D(p‖q) を最小にするものを求める操作を、p から M への 【い】 という。問題Ⅴの拡張ピタゴラスの定理より、q̂ が最小点ならば、p から q̂ への m-測地線は q̂ で M と直交する（射影定理）。さらに M が 【う】 であれば、そのような点はただ1つに定まる。逆向きの D(q‖p) を q について最小にする操作は e-射影と呼ばれ、射影先の集合が m-平坦なら一意である。

M が指数型分布族なら、問題Ⅲで見たとおり最尤推定量は η(θ̂) = (1/N) Σₖ F(xₖ) を満たす。たとえばベルヌーイ分布で N 回中 k 回成功したとき、成功確率の推定値は 【え】 である。幾何的には、「F の期待値が標本平均に等しい分布」全体の集合 A は m-平坦で p̂ を含み、e-平坦な M と点 q̂ でちょうど直交して交わる。

(2) 最大エントロピー原理。期待値 E\[F\] = c を満たす分布全体の集合 A の中で、エントロピー H(p) = −Σ p log p が最大のものを求めよう。標本空間の要素数を K、一様分布を u とすると D(p‖u) = log K − H(p) なので、エントロピー最大化は u からの D(p‖u) の最小化、すなわち u から A への e-射影である。ラグランジュの未定乗数法で解くと、最大点は p\*(x) = 【お】 の形の指数型分布族の一員になる。ここで θ は制約 E\[F\] = c に対応する 【か】 である。

拡張ピタゴラスの定理を使うと、A の任意の分布 p について D(p‖u) = D(p‖p\*) + D(p\*‖u) が成り立ち、H(p) ≤ H(p\*) が直ちに従う。統計力学のカノニカル分布 e^(−βE)/Z は、F をエネルギー、θ = −β とした特別な場合である。

(3) em アルゴリズム。観測できる変数 x と隠れ変数 z をもつモデル M = {p(x, z; θ)}（e-平坦とする）を考える。(x, z) の同時分布のうち、x の周辺分布が経験分布 p̂(x) に一致するもの全体をデータ多様体 D とよぶと、D は m-平坦である。点 p ∈ D と点 q ∈ M の間のダイバージェンス D(p‖q) を交互に最小化する。

- e ステップ：q を固定して p ∈ D について最小化する。これは q から D への 【き】 であり、解は p(x, z) = p̂(x) q(z | x)（隠れ変数の条件付き分布で補完）となる
- m ステップ：p を固定して q ∈ M について最小化する。これは p から M への m-射影、すなわち補完した完全データに対する最尤推定である

各ステップで D(p‖q) は 【く】 なので、アルゴリズムは必ず収束する方向に進むが、到達するのは一般に 【け】 であり、大域的な最小点とは限らない。統計学で広く使われる EM アルゴリズムとの関係については、{ こ }。

- ① M が指数型分布族なら、em アルゴリズムと EM アルゴリズムは一致する
- ② 2つは常に異なる推定値を与える
- ③ EM アルゴリズムは乱数を使う確率的手法なので比較できない

問1　(1) の KL ダイバージェンスの式を導き、最尤推定が p̂ から M への射影であることを説明せよ。

問2　サイコロの目 {1, 2, …, 6} 上の分布で、平均が m に固定されたものの中でエントロピーを最大にする分布が p(k) ∝ e^(θk) の形になることをラグランジュの未定乗数法で示せ。また m = 3.5 のときの θ を求めよ。

## 問題Ⅶ　クラメール＝ラオの不等式と推定の効率

次の文章を読んで、【　】に適した式・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) データ x からパラメータ ξ を推定する関数 T(x) を推定量という。すべての ξ で E\[T\] = ξ を満たすものを不偏推定量という。E\[Tⁱ\] = ∫ Tⁱ(x) p(x; ξ) dx = ξⁱ の両辺を ξʲ で微分し、問題Ⅰの E\[∂ⱼl\] = 0 を使うと

```math
E\big[ (T^i - \xi^i)\, \partial_j l \big] = \text{【ア】}
```

を得る。推定誤差とスコアは「ちょうど単位行列ぶん」相関している。パラメータが1つのとき、コーシー＝シュワルツの不等式 (E\[(T − ξ)∂l\])² ≤ E\[(T − ξ)²\] E\[(∂l)²\] から

```math
V[T] \ge \text{【イ】}
```

が従う（問1）。多次元では共分散行列について Cov(T) − g⁻¹ が半正定値になる。これがクラメール＝ラオの不等式であり、フィッシャー情報が大きい（分布の変化を見分けやすい）ほど、推定の精度の限界も良くなる。

独立同分布の N 個のデータでは、対数尤度が和になるのでフィッシャー情報は 【ウ】 となり、不偏推定量の分散は 1/N に比例して小さくできる限界をもつ。

(2) 不等式の等号が成り立つ推定量を有効推定量という。コーシー＝シュワルツの等号条件から、有効であるためにはスコアが推定誤差に比例し、∂l = g(ξ)(T − ξ) の形でなければならない。これを ξ について積分すると、p(x; ξ) は T を統計量とする指数型分布族であり、しかも ξ はその 【エ】 でなければならないことがわかる。つまり有効推定量が存在するのは、指数型分布族を期待値パラメータで表したときに限られ、そのとき有効推定量は統計量 F の 【オ】 である。

たとえばベルヌーイ分布の N 回の試行で成功割合を推定量とすると、その分散は p(1 − p)/N である。問題Ⅰより g = 1/(p(1 − p)) なので、クラメール＝ラオの不等式で 【カ】 が成り立ち、成功割合は有効推定量である。

(3) 一般のモデルでは有限の N で有効推定量は存在しないが、最尤推定量 ξ̂ は N → ∞ で

```math
\sqrt{N}\, (\hat\xi - \xi) \longrightarrow \mathcal{N}\big(0,\ \text{【キ】}\big)
```

と分布収束し、漸近的に限界を達成する（漸近有効性）。さらに指数型分布族の中に曲がって埋め込まれたモデル（曲指数型分布族）では、推定誤差の 1/N² の項が、モデルが周囲の空間の中でどれだけ曲がっているかを表す 【ク】 で決まることが知られている。情報幾何学は、推定の精度を曲率という幾何学的な量で語ることを可能にした。

クラメール＝ラオの不等式の幾何学的な意味として、フィッシャー計量で測った距離が大きい2つの分布ほど { ケ }。

- ① データから識別しやすく、パラメータの推定精度も高い
- ② データから識別しにくい
- ③ 推定精度とは無関係である

問1　パラメータが1つの場合に、不等式 V\[T\] ≥ 【イ】 を導け。等号成立条件も述べよ。

問2　分散 σ² が既知の正規分布 N(μ, σ²) から N 個の独立なデータを得たとき、標本平均の分散がクラメール＝ラオの限界に一致することを確かめよ。

## 問題Ⅷ　正規分布族の幾何（双曲平面）

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 1次元正規分布全体 {N(μ, σ²) : μ ∈ ℝ, σ > 0} を (μ, σ) を座標とする上半平面とみなす。問題Ⅰの結果から、フィッシャー計量は

```math
ds^2 = \frac{d\mu^2 + \text{【イ】}\, d\sigma^2}{\sigma^2}
```

である。μ = √2 u と変数変換すると ds² = 2(du² + dσ²)/σ² となる。(du² + dσ²)/σ² はガウス曲率 −1 の双曲平面（ポアンカレの上半平面モデル）の計量であり、計量を定数 c 倍するとガウス曲率は 1/c 倍になるので、正規分布族のガウス曲率は K = 【ロ】 で一定である（問1）。正規分布の集まりは、負の定曲率をもつ双曲幾何の世界なのである。

(2) 上半平面モデルの測地線は、境界 σ = 0 に垂直な半直線と、中心が境界上にある半円である。(μ, σ) 座標に戻すと、測地線は μ = 一定の半直線と、中心が μ 軸上にあり横方向に √2 倍引き伸ばされた 【ハ】 になる。

μ = 一定の半直線に沿った距離は ∫ √2 dσ/σ で計算でき、N(μ, σ₁²) と N(μ, σ₂²) の距離は 【ニ】 である。距離が σ の比だけで決まり、σ が小さい領域ほど同じ σ の差でも遠く離れて見える。分散の小さい分布ほど、わずかな変化でも区別しやすいことの表れである。

では平均だけが異なる N(0, σ²) と N(Δ, σ²) を結ぶ測地線はどうなるか。上の性質を踏まえると、この測地線は { ホ }。

- ① 途中で σ が大きくなる方向にふくらんだ曲線になる
- ② σ が一定の線分である
- ③ 途中で σ が小さくなる方向にへこんだ曲線になる

(3) 2つの正規分布の KL ダイバージェンスは

```math
D\big(\mathcal{N}(\mu_1, \sigma_1^2) \,\|\, \mathcal{N}(\mu_2, \sigma_2^2)\big) = \text{【ヘ】}
```

で与えられる（問2）。正規分布族は指数型分布族であり（問題Ⅲ）、θ 座標 (μ/σ², −1/(2σ²)) と η 座標 (μ, μ² + σ²) をもつ。したがって e-接続・m-接続に関する曲率はともに 【ト】 である。同じ空間が、レヴィ＝チヴィタ接続では曲がっており（K = 【ロ】）、e-接続・m-接続ではまっすぐである。「平坦かどうか」は接続の選び方に依存するという、情報幾何学の要点がここに現れている。

(4) 平均を固定した多変量正規分布 N(0, Σ)（Σ は正定値対称行列）のフィッシャー計量は

```math
ds^2 = \text{【チ】}\; \mathrm{tr}\big( \Sigma^{-1} d\Sigma\, \Sigma^{-1} d\Sigma \big)
```

で与えられる。1次元（Σ = σ²）では dΣ = 2σ dσ なので、(1) の σ 方向の成分 2dσ²/σ² と一致する。この計量は Σ ↦ AΣAᵀ（A は正則行列）で不変であり、2点 Σ₁, Σ₂ の測地距離は、行列 【リ】 の固有値 λ₁, …, λₙ を用いて d² = (1/2) Σᵢ (log λᵢ)² と表される。共分散行列の比較、拡散テンソル画像の解析、脳波の信号処理などで実際に使われている距離である。

問1　問題Ⅳの微分幾何学の公式（F = 0 のとき）

```math
K = -\frac{1}{2\sqrt{EG}} \left[ \frac{\partial}{\partial u}\left( \frac{G_u}{\sqrt{EG}} \right) + \frac{\partial}{\partial v}\left( \frac{E_v}{\sqrt{EG}} \right) \right]
```

を u = μ、v = σ、E = 1/σ²、G = 2/σ² に適用して、K = 【ロ】 を確かめよ。

問2　【ヘ】を導け。また μ₂ = μ₁ + dμ、σ₂ = σ₁ + dσ として2次まで展開し、問題Ⅱ(2) のとおり (1/2) ds² が得られることを確かめよ。
