## 使い方

微分幾何学の基礎を6テーマに分け、京大物理と同じ「誘導つきの長文＋空欄補充＋選択＋問」形式で1テーマ＝大問1題にまとめた。前半3題で ℝ³ 内の曲線・曲面の古典論を、後半3題で抽象的な多様体と微分形式を扱い、「曲面の内側だけで測れる量」から多様体論へ橋渡しする流れになっている。各大問は30〜40分が目安。

- 【ア】などの空欄には式・数値・語句を入れる。前の空欄の答えを後で使うことがある。
- { ケ } などの選択欄には①〜③から1つ選ぶ。
- 「問」は導出・証明・計算。物理の記述問題と同じく、論理を短く書く。
- 記号は京大物理にならい、問題Ⅰ・Ⅳはカタカナ、問題Ⅱ・Ⅴはイロハ、問題Ⅲ・Ⅵはひらがな。
- 解答と解説は末尾にまとめた。

| 大問 | テーマ | 到達目標 |
| --- | --- | --- |
| Ⅰ | 曲線の幾何 | 弧長・曲率・捻率、フルネ＝セレの公式を計算できる |
| Ⅱ | 曲面と第一基本形式 | 長さ・面積・等長性を E, F, G で表せる |

## 問題Ⅰ　曲線の幾何（曲率・捻率・フルネ＝セレの公式）

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) ℝ³ 内の曲線 c(t) で、すべての t について c′(t) ≠ 0 を満たすものを正則曲線という。t₀ からの弧長

```math
s(t) = \int_{t_0}^{t} |c'(u)|\, du
```

は t の狭義増加関数なので、s を新しいパラメータにとり直せる。弧長パラメータで表すと、速さは |dc/ds| = 【ア】 となり、曲線の形だけを反映した量を取り出せる。以下 ′ は s による微分とする。

単位接ベクトルを e₁ = c′(s) とおく。|e₁|² = 1 の両辺を s で微分すると e₁ · e₁′ = 【イ】 となるので、e₁′ は e₁ に直交する。e₁′ は「進行方向がどれだけ速く向きを変えるか」を表す。

平面曲線では、e₁ を反時計回りに 90° 回転したベクトルを e₂ とすると e₁′ = κe₂ と書け、κ を符号付き曲率という。たとえば半径 r の円 c(s) = (r cos(s/r), r sin(s/r)) を反時計回りにたどると、e₁ = (−sin(s/r), cos(s/r))、e₁′ = −(1/r)(cos(s/r), sin(s/r))、e₂ = (−cos(s/r), −sin(s/r)) なので κ = 【ウ】 である。一般の曲線でも 1/|κ| は、その点で曲線に最もよく接する円（接触円）の半径に等しい。

(2) 空間曲線で κ = |e₁′| > 0 のとき、主法線ベクトル e₂ = e₁′/κ と従法線ベクトル e₃ = e₁ × e₂ を定める。正規直交枠 (e₁, e₂, e₃) を曲線に沿って動かすと、その変化は次のフルネ＝セレの公式で表される。

```math
e_1' = \kappa e_2, \qquad e_2' = -\kappa e_1 + \tau e_3, \qquad e_3' = \text{【エ】}
```

τ を捩率（れいりつ、捻率とも書く）といい、曲線が接触平面（e₁, e₂ の張る平面）から「ねじれて」出ていく速さを表す。係数を並べた 3×3 行列は 【オ】 になっている。これは枠が常に正規直交であることから、eᵢ · eⱼ = 一定 を微分して得られる性質である。

具体例として常螺旋 c(t) = (a cos t, a sin t, bt)（a > 0）を考える。|c′(t)| = 【カ】 は一定なので s は t の定数倍である。計算すると

- 曲率 κ = 【キ】
- 捻率 τ = 【ク】

となり、どちらも一定である。b = 0 とすると半径 a の円に戻り、κ = 1/a、τ = 0 となることを確かめておくとよい。逆に、κ と τ を s の関数として与えると、曲線は空間内の位置と向き（合同変換）を除いて一意に決まる（曲線論の基本定理）。とくに κ > 0 で τ ≡ 0 である曲線は { ケ }。

- ① ある平面に含まれる
- ② 直線である
- ③ 常螺旋である

問1　e₁′ と e₂′ の式および (e₁, e₂, e₃) の正規直交性を用いて、e₃′ = 【エ】 を導け。

問2　平面曲線 c(t) = (x(t), y(t)) を一般のパラメータで表したとき、符号付き曲率は

```math
\kappa = \frac{x'y'' - x''y'}{(x'^2 + y'^2)^{3/2}}
```

で与えられる（′ は t による微分）。この公式を用いて、放物線 y = x² の原点における曲率と接触円の半径を求めよ。

## 問題Ⅱ　曲面と第一基本形式

次の文章を読んで、【　】に適した式・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 平面領域 D から ℝ³ への滑らかな写像 p(u, v) で、各点で pᵤ と pᵥ が一次独立なものを（正則な）曲面片という。pᵤ, pᵥ が張る平面が接平面であり、単位法線ベクトルは n = (pᵤ × pᵥ)/|pᵤ × pᵥ| である。

曲面上の曲線 c(t) = p(u(t), v(t)) の速度は連鎖律により c′ = u′pᵤ + v′pᵥ なので、その長さの2乗は

```math
|c'|^2 = E\,u'^2 + 2F\,u'v' + G\,v'^2, \qquad E = p_u \cdot p_u,\quad F = \text{【イ】},\quad G = p_v \cdot p_v
```

となる。微小な線素で書けば ds² = E du² + 2F du dv + G dv² であり、これを第一基本形式という。曲面上の曲線の長さは、空間を知らなくても E, F, G だけから計算できる。

(2) 面積も第一基本形式で表せる。微小な平行四辺形 pᵤ du, pᵥ dv の面積は |pᵤ × pᵥ| du dv であり、ベクトルの恒等式 |a × b|² = |a|²|b|² − (a · b)² を使うと

```math
\text{面積} = \iint_D \sqrt{\text{【ロ】}}\; du\, dv
```

となる。半径 R の球面 p(θ, φ) = (R sin θ cos φ, R sin θ sin φ, R cos θ)（0 < θ < π、0 < φ < 2π）では、E = 【ハ】、F = 【ニ】、G = 【ホ】 であり、面積は 【ヘ】 となる。また座標曲線（u 一定の曲線と v 一定の曲線）のなす角 ω は cos ω = F/√(EG) で与えられるので、F = 0 は座標曲線が直交することを意味する。

(3) 2つの曲面の間の対応で、曲線の長さをすべて保つものを等長対応という。適当なパラメータで第一基本形式（E, F, G）が一致すれば、2つの曲面は（局所的に）等長である。たとえば平面 p(u, v) = (u, v, 0) の第一基本形式は du² + dv² である。円柱 q(u, v) = (cos u, sin u, v) を計算すると E = 【ト】、F = 0、G = 1 となって平面と一致する。紙を丸めて円柱を作っても、紙の上の長さが変わらないことの数式表現である。

回転面 p(u, v) = (f(u) cos v, f(u) sin v, g(u))（f > 0）では、E = f′² + g′²、F = 0、G = 【チ】 となる。断面曲線 (f(u), g(u)) を弧長でパラメータ表示しておくと f′² + g′² = 1 なので E = 【リ】 となり、第一基本形式は du² + f(u)² dv² という簡潔な形になる。この形は問題Ⅳで曲率を計算するときに便利である。

第一基本形式だけで決まる量を、曲面の内在的な量という。次のうち、第一基本形式だけで決まるものは { ヌ }。

- ① 曲面上の曲線の長さ、交わる角、領域の面積
- ② 単位法線ベクトルの向き
- ③ 空間内での曲面の曲がり方を表す第二基本形式（問題Ⅲ）

問1　恒等式 |a × b|² = |a|²|b|² − (a · b)² を成分計算などで示し、面積要素が【ロ】の平方根で与えられることを確かめよ。

問2　円錐面（頂点を除く）p(u, v) = (u cos v, u sin v, u)（u > 0）の第一基本形式を求めよ。さらに、平面の極座標 (r, ϑ) における第一基本形式 dr² + r² dϑ² と比べ、r = √2 u、ϑ = v/√2 と対応させれば円錐面が平面の一部と局所的に等長であることを示せ。

## 問題Ⅲ　第二基本形式とガウス曲率

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 第一基本形式は曲面の「内側の長さ」を測るが、曲面が空間内でどう曲がっているかは測らない。それを測るのが、2階微分の法線成分

```math
L = p_{uu} \cdot n, \qquad M = p_{uv} \cdot n, \qquad N = p_{vv} \cdot n
```

を係数とする第二基本形式 L du² + 2M du dv + N dv² である。pᵤ · n = 0 を u で微分すると L = 【あ】 と書けるので、第二基本形式は「法線ベクトル n が動く速さ」を表しているともいえる。

曲面上の曲線を弧長パラメータで表すと、加速度 c″ の法線成分 κₙ = c″ · n は曲線の速度の方向だけで決まり、

```math
\kappa_n = \frac{L\,u'^2 + 2M\,u'v' + N\,v'^2}{E\,u'^2 + 2F\,u'v' + G\,v'^2}
```

となる（′ は任意のパラメータでの微分でよい）。κₙ を法曲率という。

(2) 接平面内の方向を回すと法曲率は変化し、その最大値と最小値を主曲率 κ₁, κ₂、それを与える方向を主方向という。主曲率は行列 (第一基本形式の行列)⁻¹(第二基本形式の行列) の固有値として求まり、

```math
K = \kappa_1 \kappa_2 = \text{【い】}, \qquad H = \frac{\kappa_1 + \kappa_2}{2} = \frac{EN - 2FM + GL}{2(EG - F^2)}
```

をそれぞれガウス曲率、平均曲率という。

半径 R の球面で外向き単位法線 n = p/R をとると、nᵤ = pᵤ/R、nᵥ = pᵥ/R となり、第二基本形式は第一基本形式の −1/R 倍になる。したがってすべての方向で法曲率は等しく、κ₁ = κ₂ = 【う】、K = 【え】 である。法線の向きを反転すると主曲率の符号は変わるが、K は変わらない。

(3) 曲面が z = f(x, y)、f(0, 0) = 0、∇f(0, 0) = 0 と表されているとき、原点では E = G = 1、F = 0、n = (0, 0, 1)、L = fₓₓ、M = fₓᵧ、N = fᵧᵧ となるので、K(0) = 【お】 である。つまりガウス曲率は、接平面からの「高さ関数」のヘッセ行列の行列式である。

- 鞍形 z = xy の原点：K = 【か】
- 放物面 z = x² + y² の原点：K = 【き】

K > 0 の点を楕円点（近くで曲面が接平面の片側にある）、K < 0 の点を 【く】 点（接平面を横切る鞍の形）、K = 0 の点を放物点または平坦点という。半径 r の円柱面では、主曲率の絶対値は母線方向で 0、円周方向で 1/r なので K = 【け】 である。

なお、球面のように κ₁ = κ₂ となる点（臍点）以外では主方向はちょうど2つあり、それらは { こ }。

- ① 互いに直交する
- ② 互いに平行である
- ③ 一般には任意の角度をなす

問1　鞍形 z = xy の原点における主曲率と主方向を求めよ。

問2　ある点の主曲率を κ₁, κ₂、対応する単位主方向を e₁, e₂ とする。e₁ と角 θ をなす単位接ベクトル方向の法曲率が

```math
\kappa_n(\theta) = \kappa_1 \cos^2\theta + \kappa_2 \sin^2\theta
```

となること（オイラーの公式）を示せ。（ヒント：e₁, e₂ を座標軸とする正規直交座標で第一・第二基本形式を表す。）

## 問題Ⅳ　測地線・驚異の定理・ガウス＝ボネの定理

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 曲面上の曲線 c(s)（弧長パラメータ）の加速度を、法線方向と、接平面内で速度に直交する方向に分解する。

```math
c'' = \kappa_g\, (n \times c') + \kappa_n\, n
```

κₙ は問題Ⅲの法曲率、κg（右辺第1項の係数）を測地的曲率という。曲面上に住む生き物には法線方向は見えないので、κg こそが「曲面の中で感じる曲がり具合」である。κg ≡ 0、すなわち c″ が常に 【ア】 に平行な曲線を測地線という。曲面上の2点を結ぶ最短の曲線は測地線になる。

半径 R の球面上の大円を一定の速さでたどると、加速度は球の中心を向くので法線に平行であり、大円は測地線である。一方、赤道以外の緯線では加速度が回転軸を向き、法線と平行にならないので測地線ではない。

(2) 座標 (u¹, u²) = (u, v) と第一基本形式の係数 gᵢⱼ（g₁₁ = E、g₁₂ = g₂₁ = F、g₂₂ = G）を用いると、測地線の方程式は

```math
\frac{d^2u^k}{ds^2} + \sum_{i,j} \Gamma^k_{ij} \frac{du^i}{ds} \frac{du^j}{ds} = 0, \qquad \Gamma^k_{ij} = \frac{1}{2} \sum_{l} g^{kl} \left( \partial_i g_{jl} + \partial_j g_{il} - \partial_l g_{ij} \right)
```

と書ける（gᵏˡ は gᵢⱼ の逆行列の成分）。クリストッフェル記号 Γ は 【イ】 とその微分だけで決まるので、測地線も内在的な概念である。

平面の極座標 ds² = dr² + r² dϑ² で計算すると、0 でないものは Γʳ（ϑϑ）= 【ウ】、Γᶿ（rϑ）= Γᶿ（ϑr）= 【エ】 である。測地線の方程式は r″ − r ϑ′² = 0、ϑ″ + (2/r) r′ϑ′ = 0 となり、第2式は (r²ϑ′)′ = 0、すなわち r²ϑ′ = 【オ】 を意味する。これは等速直線運動における角運動量保存と同じ式であり、平面の測地線は直線であることが確かめられる。

(3) ガウスの驚異の定理：ガウス曲率 K は、第二基本形式を使って定義したにもかかわらず、第一基本形式とその微分だけで表せる。F = 0 の直交座標系では

```math
K = -\frac{1}{2\sqrt{EG}} \left[ \frac{\partial}{\partial u}\left( \frac{G_u}{\sqrt{EG}} \right) + \frac{\partial}{\partial v}\left( \frac{E_v}{\sqrt{EG}} \right) \right]
```

である。問題Ⅱの球面（u = θ、v = φ、E = R²、G = R² sin²θ）に適用すると K = 【カ】 となり、問題Ⅲの結果と一致する。この定理から、K が異なる曲面どうしは局所的にも等長になりえない。平面は K = 0、球面は K > 0 なので、地球の表面の一部を長さの比を一切変えずに平面の地図に写すことは 【キ】。一方、円柱面は K = 【ク】 なので、問題Ⅱで見た平面との等長性と矛盾しない。

(4) 3本の測地線で囲まれた曲面上の三角形 T の内角を α, β, γ とすると、ガウス＝ボネの定理

```math
\iint_T K\, dA = \alpha + \beta + \gamma - \text{【ケ】}
```

が成り立つ。たとえば単位球面上で、北極と赤道上の経度 0°、90° の2点を頂点とする三角形は3つの角がすべて直角で、面積は球面の 1/8 なので、両辺がともに π/2 になる。この定理により、K < 0 で一定の曲面（双曲平面）上の測地三角形の内角の和は { コ }。

- ① π より小さい
- ② π に等しい
- ③ π より大きい

問1　問題Ⅱの回転面で、断面曲線を弧長パラメータで表したとき、子午線（v = 一定の曲線）が測地線であることを示せ。（ヒント：c″ が pᵤ と pᵥ の両方に直交することを示せばよい。）

問2　単位球面 ds² = dθ² + sin²θ dφ² のクリストッフェル記号を計算し、測地線に沿って sin²θ · (dφ/ds) が一定であること（クレローの関係）を導け。

## 問題Ⅴ　可微分多様体と接空間

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 問題Ⅳで見たように、曲面の内在的な幾何は周りの空間がなくても語れる。そこで「各点の近くで ℝⁿ と同じに見える空間」を直接定義する。ハウスドルフかつ第二可算な位相空間 M が、開集合 U と同相写像 φ : U → φ(U) ⊂ ℝⁿ の組（チャート）で覆われているとき、M を n 次元位相多様体という。2つのチャートが重なる部分では座標変換 φβ ∘ φα⁻¹ が定まり、これがすべて C^∞ 級であるとき M を可微分多様体という。

例として円周 S¹ = {(x, y) : x² + y² = 1} を考える。北極 N = (0, 1) からの立体射影 φN(x, y) = x/(1 − y) は S¹ \\ {N} 上のチャートであり、南極 S = (0, −1) からの立体射影 φS(x, y) = x/(1 + y) は S¹ \\ {S} 上のチャートである。重なり部分で

```math
\varphi_N \cdot \varphi_S = \frac{x^2}{1 - y^2} = \text{【イ】}
```

なので、座標変換は t ↦ 【ロ】（t ≠ 0）であり、C^∞ 級である。S¹ はコンパクトだが ℝ の空でない開集合はコンパクトでないので、S¹ を1枚のチャートで覆うことはできず、少なくとも 【ハ】 枚が必要である。

(2) 多様体は ℝᴺ の中にあるとは限らないので、接ベクトルを「矢印」として定義できない。そこで「方向微分」としての性質を定義に採用する。点 p での接ベクトルとは、p の近くの滑らかな関数に実数を対応させる線形写像 v で、ライプニッツ則 v(fg) = v(f) g(p) + f(p) v(g) を満たすものである。定数関数 1 については v(1) = v(1·1) = 2v(1) より v(1) = 【ニ】 となる。

局所座標 (x¹, …, xⁿ) のもとで偏微分 ∂/∂xⁱ|ₚ は接ベクトルであり、接ベクトル全体 TₚM はこれらを基底とする 【ホ】 次元のベクトル空間になる。別の座標 (y¹, …, yⁿ) をとると、連鎖律から

```math
\frac{\partial}{\partial y^j} = \sum_i \frac{\partial x^i}{\partial y^j} \frac{\partial}{\partial x^i}
```

が成り立つ。同じ接ベクトルを v = Σ aⁱ ∂/∂xⁱ = Σ bʲ ∂/∂yʲ と2通りに表すと、成分は bʲ = 【ヘ】 と変換される。物理でいう「反変ベクトル」の変換則である。

(3) 滑らかな写像 F : M → N の点 p での微分 dFₚ : TₚM → T\_F(p)N を (dFₚv)(g) = v(g ∘ F) で定める。座標で表すと dFₚ はヤコビ行列である。

F : ℝⁿ⁺¹ → ℝ、F(x) = |x|² とすると dFₓ(v) = 2x · v であり、F⁻¹(1) 上で x ≠ 0 なので 1 は正則値である。正則値定理により球面 Sⁿ = F⁻¹(1) は n 次元の部分多様体であり、点 p での接空間は TₚSⁿ = 【ト】 と、dFₚ の核として求まる。

関数 f の微分 df は接ベクトル v に v(f) を対応させる線形形式（余接ベクトル）で、座標の微分は dxⁱ(∂/∂xʲ) = 【チ】 を満たす。また2つのベクトル場 X, Y に対し、\[X, Y\]f = X(Yf) − Y(Xf) で定まる括弧積は、2階微分の項が打ち消し合うので再びベクトル場になる。たとえば ℝ² で \[∂/∂x, x ∂/∂y\] = 【リ】 である。

可微分多様体の定義で座標変換の滑らかさを要求するのは { ヌ }。

- ① 関数の微分可能性が、どのチャートで調べても同じ結論になるようにするため
- ② 多様体をハウスドルフ空間にするため
- ③ 多様体に距離（計量）を入れるため

問1　立体射影 φN の逆写像が t ↦ (2t/(t² + 1), (t² − 1)/(t² + 1)) であることを確かめよ（像が S¹ 上にあることと、φN と合成すると恒等写像になることを示す）。

問2　成分の変換則【ヘ】を導け。また ℝ² で直交座標 (x, y) と極座標 (r, ϑ) を用いるとき、∂/∂ϑ = −y ∂/∂x + x ∂/∂y を示せ。

## 問題Ⅵ　微分形式とストークスの定理

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 多様体上で積分を座標によらずに扱うための道具が微分形式である。1次微分形式は ω = a₁dx¹ + … + aₙdxⁿ の形をしており、問題Ⅴの余接ベクトルを点ごとに与えたものである。k 次形式は dx^i ∧ dx^j ∧ … の一次結合で、外積 ∧ は反対称 dx ∧ dy = −dy ∧ dx を満たす。したがって dx ∧ dx = 【あ】 である。ℝ² で計算すると

```math
(a\,dx + b\,dy) \wedge (c\,dx + e\,dy) = \text{【い】}\; dx \wedge dy
```

となり、係数に行列式が現れる。2次形式 dx ∧ dy は「向きのついた面積要素」であり、極座標 x = r cos ϑ、y = r sin ϑ に変換すると dx ∧ dy = 【う】 dr ∧ dϑ となる。重積分の変数変換でヤコビアンが現れる理由は、この計算に集約されている。

(2) 外微分 d は k 次形式を (k + 1) 次形式に写す。関数（0次形式）には df = Σ (∂f/∂xⁱ) dxⁱ、一般には d(a dx^I) = da ∧ dx^I と定める。偏微分の順序交換が可能なことと外積の反対称性から、つねに d ∘ d = 【え】 となる。

ℝ³ では1次形式・2次形式をベクトル場と同一視でき、外微分は次のように対応する。

| 形式 | d の作用 | ベクトル解析での対応 |
| --- | --- | --- |
| 0次形式 f | df | grad f |
| 1次形式 | dω | 【お】 |
| 2次形式 | dω | div |

d ∘ d = 【え】 は、ベクトル解析の公式 rot(grad f) = 0 と div(rot A) = 0 をまとめて表している。

(3) ストークスの定理：境界 ∂M をもつ向き付けられた k 次元多様体 M と (k − 1) 次形式 ω に対し

```math
\int_M d\omega = \int_{\partial M} \omega
```

が成り立つ。k = 1 なら微積分の基本定理そのものである。平面領域 D と ω = P dx + Q dy の場合、dω = 【か】 dx ∧ dy となり、グリーンの定理が得られる。とくに ω = (x dy − y dx)/2 とすると dω = dx ∧ dy なので、D の面積は境界の線積分 (1/2)∮(x dy − y dx) で求まる。半径 a の円板で x = a cos t、y = a sin t とおくと被積分関数は a² dt となり、面積は 【き】 である。ガウスの発散定理や古典的なストークスの定理も、この1つの式の特別な場合である。

(4) dω = 0 となる形式を閉形式、ω = dη と書ける形式を完全形式という。d ∘ d = 0 より完全形式は閉形式である。では逆はどうか。ℝ² \\ {0} 上の1次形式

```math
\omega = \frac{-y\,dx + x\,dy}{x^2 + y^2}
```

を考えると、計算により dω = 【く】 である。しかし単位円を反時計回りに一周する積分は ∮ω = 【け】 であり 0 でない。もし ω = dη と書けたなら、ストークスの定理（k = 1）より閉曲線上の積分は 0 になるはずなので、ω は完全形式ではない。原点という「穴」があるために閉形式が完全形式にならないのであり、閉形式と完全形式のずれが空間の位相を検出する（ド・ラーム・コホモロジー）。一方、ℝⁿ 全体や星形の領域では、閉形式は { こ }。

- ① 必ず完全形式である（ポアンカレの補題）
- ② 必ずしも完全形式ではない
- ③ 必ず 0 である

問1　ℝ² 上の滑らかな関数 f について、d(df) = 0 を直接計算で確かめよ。

問2　(4) の ω は、局所的には極座標の角度 ϑ を用いて ω = dϑ と書けることを示せ。また、それにもかかわらず ω が ℝ² \\ {0} 全体で完全形式にならない理由を、ϑ の多価性と ∮ω = 【け】 を結びつけて説明せよ。
