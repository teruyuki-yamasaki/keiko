## 使い方

測度論的確率論の基礎を6テーマに分け、京大物理と同じ「誘導つきの長文＋空欄補充＋選択＋問」形式で1テーマ＝大問1題にまとめた。各大問は30〜40分を目安に、空欄を前から順に埋めると定義から主要定理まで一本道でたどれるように作ってある。

- 【ア】などの空欄には式・集合・数値・語句を入れる。前の空欄の答えを後で使うことがある。
- { コ } などの選択欄には①〜③から1つ選ぶ。前の空欄が解けなくても答えられる。
- 「問」は導出・証明・具体例の作成。答案は物理の記述問題と同じく、論理を短く書く。
- 記号は京大物理にならい、問題Ⅰ・Ⅳはカタカナ（ア〜）、問題Ⅱ・Ⅴはイロハ（イ〜）、問題Ⅲ・Ⅵはひらがな（あ〜）。
- 解答と解説は末尾にまとめた。

## 問題Ⅰ　σ-加法族と可測空間

次の文章を読んで、【　】に適した式・集合・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。なお、【　】はすでに【　】で与えられたものと同じものを表す。また、問1・問2では指示にしたがって答えよ。

(1) 確率を考える対象の全体を集合 Ω とし、確率を割り当てたい Ω の部分集合（事象）の族を F とする。F が次の3条件を満たすとき、F を σ-加法族といい、組 (Ω, F) を可測空間という。

- (i) Ω ∈ F
- (ii) A ∈ F ならば Aᶜ ∈ F
- (iii) A₁, A₂, … ∈ F ならば ∪ₙ Aₙ ∈ F

この3条件から、可算個の共通部分についても閉じていることがわかる。実際、ド・モルガンの法則より ∩ₙ Aₙ = (【ア】)ᶜ であり、右辺の括弧内は (ii)(iii) により F に属する。同様に、空集合は ∅ = (【イ】)ᶜ と書けるので F に属する。

具体例として Ω = {1, 2, 3, 4} とし、A = {1, 2} を含む最小の σ-加法族 σ({A}) を求めよう。(i)(ii) より、少なくとも ∅, Ω, A と、A の補集合 【ウ】 を含まなければならない。この4つの集合族はすでに (i)〜(iii) を満たすので、σ({A}) = {∅, A, 【ウ】, Ω} であり、その要素数は 【エ】 である。より一般に、Ω が互いに素な k 個の空でない集合 B₁, …, Bₖ に分割されているとき、それらで生成される σ-加法族は「いくつかの Bᵢ の和集合」全体と一致し、要素数は 【オ】 となる。

(2) 任意の部分集合族 C に対し、C を含む σ-加法族はべき集合 2^Ω を始め少なくとも1つ存在する。それら全ての共通部分をとると、それは再び σ-加法族となり、C を含む最小の σ-加法族になる。これを σ(C) と書き、C で生成される σ-加法族という。

ℝ の開集合全体で生成される σ-加法族 B(ℝ) をボレル集合族という。実は B(ℝ) は半直線の族 C = {(−∞, x\] : x ∈ ℝ} でも生成される。これを確かめるには、C から開区間がつくれることを示せばよい。まず半開区間は (a, b\] = (−∞, b\] \\ 【カ】 と書ける。次に開区間は可算和

```math
(a, b) = \bigcup_{n=1}^{\infty} \left(a,\ \text{【キ】}\right]
```

で表せるから σ(C) に属する。ℝ の開集合は開区間の可算和で書けるので B(ℝ) ⊂ σ(C) が従う。逆向きの包含は (−∞, x\] が閉集合であることから明らかである。なお1点集合も {x} = ∩ₙ (x − 1/n, 【ク】\] と表せるので B(ℝ) に属する。

(3) 条件 (iii) を「有限個の和について閉じている」に弱めたものを有限加法族という。Ω = ℕ（自然数全体）とし、F₀ を「有限集合、または補集合が有限集合であるもの」全体とする。F₀ は (i)(ii) を満たし、有限和でも閉じている。偶数全体の集合 E = {2, 4, 6, …} は1点集合 {2n} の可算和だが、E も Eᶜ も無限集合なので E は F₀ に属さない。したがって F₀ は { ケ }。

- ① σ-加法族である
- ② 有限加法族だが σ-加法族ではない
- ③ 有限加法族でもない

σ-加法族が「可算」個の操作で閉じていることは、確率の連続性や極限操作（問題Ⅱ以降）を扱うために本質的である。可算和の代わりに非可算和まで許すと、ℝ 上で長さ（ルベーグ測度）と両立しなくなることが知られている。このことから、F を Ω のべき集合ではなく適切な σ-加法族にとる理由は、測度をうまく定義できる集合に限るためだとわかる。

問1　Ω = ℕ において、すべての1点集合 {n} を含む最小の σ-加法族は、べき集合 2^ℕ に一致することを示せ。

問2　Ω = {1, 2, 3} とする。2つの σ-加法族 F₁ = σ({{1}})、F₂ = σ({{2}}) の和集合 F₁ ∪ F₂ は σ-加法族でないことを、具体的な集合を挙げて示せ。また、その結果から σ(F₁ ∪ F₂) を求めよ。

## 問題Ⅱ　確率測度の性質・連続性・ボレル＝カンテリの補題

次の文章を読んで、【　】に適した式・集合・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 可測空間 (Ω, F) 上の関数 P : F → \[0, 1\] が P(Ω) = 1 と可算加法性

```math
A_1, A_2, \ldots \in \mathcal{F}\ \text{が互いに素} \implies P\Big(\bigcup_{n=1}^{\infty} A_n\Big) = \sum_{n=1}^{\infty} P(A_n)
```

を満たすとき、P を確率測度といい、(Ω, F, P) を確率空間という。A₁ = Ω、A₂ = A₃ = … = ∅ とおくと可算加法性から P(∅) = 【イ】 が従い、これと組み合わせると有限加法性も得られる。A ⊂ B のとき B は A と 【ロ】 の互いに素な和なので P(B) = P(A) + P(【ロ】) ≥ P(A)（単調性）。また一般の A, B について P(A ∪ B) = P(A) + P(B) − 【ハ】 が成り立つ。

(2) 可算加法性の最も重要な帰結は「確率の連続性」である。増加列 A₁ ⊂ A₂ ⊂ … について A = ∪ₙ Aₙ とする。A₀ = ∅ とし、Bₖ = Aₖ \\ Aₖ₋₁（k = 1, 2, …）とおくと、Bₖ は互いに素で、B₁ ∪ B₂ ∪ … ∪ Bₙ = 【ニ】、B₁ ∪ B₂ ∪ …（無限和）= A となる。したがって可算加法性より

```math
P(A) = \sum_{k=1}^{\infty} P(B_k) = \lim_{n\to\infty} \text{【ホ】} = \lim_{n\to\infty} P(A_n)
```

を得る。減少列 A₁ ⊃ A₂ ⊃ … についても P(∩ₙ Aₙ) = limₙ P(Aₙ) が成り立つ（問1）。ただし、この減少列の連続性は測度が有限であることを使っている。たとえば ℝ 上のルベーグ測度 λ と Aₙ = \[n, ∞) を考えると、すべての n で λ(Aₙ) = 【ヘ】 だが、∩ₙ Aₙ = 【ト】 なので連続性が成り立たない。

(3) 事象列 A₁, A₂, … に対し、上極限事象を

```math
\limsup_{n\to\infty} A_n = \bigcap_{n=1}^{\infty} \bigcup_{k=n}^{\infty} A_k
```

で定める。これは「無限に多くの Aₙ が起こる」という事象を表す。∪\_{k≥n} Aₖ は n について減少列なので、(2) の連続性と劣加法性（可算加法性から導かれる）により

```math
P\Big(\limsup_{n\to\infty} A_n\Big) = \lim_{n\to\infty} P\Big(\bigcup_{k=n}^{\infty} A_k\Big) \le \lim_{n\to\infty} \text{【チ】}
```

となる。Σₙ P(Aₙ) < ∞ ならば【チ】は収束級数の残りの部分なので 0 に収束し、P(limsup Aₙ) = 【リ】 を得る。これをボレル＝カンテリの第1補題という。独立性を仮定していないことに注意せよ。

(4) Ω = \[0, 1\]、F = B(\[0, 1\])、P を長さ（ルベーグ測度）とする。各1点 {x} の確率は 0 である。\[0, 1\] に含まれる有理数全体の集合 Q₀ の確率は { ヌ }。

- ① 0 である。Q₀ は可算集合なので可算加法性から求まる
- ② 1 である。Q₀ は \[0, 1\] で稠密だから
- ③ Q₀ は F に属さないので定義できない

問1　増加列についての連続性を用いて、減少列 A₁ ⊃ A₂ ⊃ … について P(∩ₙ Aₙ) = limₙ P(Aₙ) を示せ。

問2　ある実験を繰り返し、事象 Aₙ を「n 回目に成功する」とする。試行どうしの独立性は仮定せず、P(Aₙ) = 1/n² であることだけがわかっている。成功が無限回起こる確率を求め、理由を述べよ。

## 問題Ⅲ　確率変数・分布・分布関数

次の文章を読んで、【　】に適した式・集合・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 確率空間 (Ω, F, P) 上の関数 X : Ω → ℝ が確率変数であるとは、任意のボレル集合 B ∈ B(ℝ) に対して逆像 X⁻¹(B) = {ω : X(ω) ∈ B} が 【あ】 に属することをいう。つまり「X の値が B に入る」という出来事に確率が定まっていることを要請している。

すべてのボレル集合を調べるのは大変だが、実は任意の x ∈ ℝ に対し {X ≤ x} ∈ F であれば十分である。これを示すため、G = {B ⊂ ℝ : X⁻¹(B) ∈ F} とおく。逆像は集合演算と交換し、X⁻¹(Bᶜ) = 【い】、X⁻¹(∪ₙ Bₙ) = ∪ₙ X⁻¹(Bₙ) が成り立つ。これと X⁻¹(ℝ) = Ω から G は σ-加法族である。仮定より G は半直線 (−∞, x\] をすべて含むので、問題Ⅰ(2) の結果から G ⊃ 【う】 となり、X は確率変数である。このように「生成系で確かめれば十分」という論法は、測度論で繰り返し使われる。

(2) 確率変数 X に対し、μ(B) = P(【え】)（B ∈ B(ℝ)）で定まる (ℝ, B(ℝ)) 上の確率測度 μ を X の分布という。Ω 上の確率 P を X で ℝ に「押し出した」測度であり、像測度とも呼ばれる。分布関数を F(x) = μ((−∞, x\]) = P(X ≤ x) で定めると、F は単調非減少であり、

- x → −∞ のとき F(x) → 【お】、x → +∞ のとき F(x) → 【か】
- 右連続：F(x + 1/n) → F(x)（n → ∞）

が成り立つ。右連続性は、半直線 (−∞, x + 1/n\] が n について 【き】 であり、その共通部分が (−∞, x\] であることと、問題Ⅱ(2) の連続性から従う。一方、左極限 F(x−) = lim（y ↑ x）F(y) は P(X < x) に等しく、1点の確率は P(X = x) = F(x) − 【く】 で与えられる。分布関数が連続であることと、すべての1点の確率が 0 であることは同値である。

(3) Ω = \[0, 1\]、F = B(\[0, 1\])、P をルベーグ測度とし、X(ω) = −log ω（ω > 0）、X(0) = 0 と定める。X は連続関数（ω > 0 の部分）なので確率変数である。t ≥ 0 に対して {X > t} = {ω : ω < e^(−t)} だから P(X > t) = 【け】 となり、X はパラメータ 1 の指数分布に従う。このように「一様分布から好きな分布をつくる」操作は、乱数生成の基礎になっている。一般に、連続かつ狭義単調増加な分布関数 F と、\[0, 1\] 上の一様分布に従う U に対し、F⁻¹(U) の分布関数は { こ }。

- ① F である
- ② 1 − F である
- ③ F⁻¹ である

問1　X, Y が確率変数ならば X + Y も確率変数であることを、集合の等式

```math
\{X + Y < x\} = \bigcup_{q \in \mathbb{Q}} \big(\{X < q\} \cap \{Y < x - q\}\big)
```

を用いて説明せよ。等式自体の成立理由も述べること。

問2　確率変数 X の分布関数が次で与えられている。

```math
F(x) = \begin{cases} 0 & (x < 0) \\ \dfrac{1}{2} & (0 \le x < 1) \\ \dfrac{x+1}{4} & (1 \le x < 3) \\ 1 & (x \ge 3) \end{cases}
```

P(X = 0)、P(1/2 < X ≤ 2) を求めよ。また、この分布が離散分布でも密度関数をもつ分布でもないことを説明せよ。

## 問題Ⅳ　期待値とルベーグ積分・収束定理

次の文章を読んで、【　】に適した式・数値・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 期待値は「値 × 確率」の和を、一般の確率変数に拡張したものである。互いに素な A₁, …, Aₖ ∈ F と実数 a₁, …, aₖ ≥ 0 を用いて s = a₁1(A₁) + … + aₖ1(Aₖ) と書ける関数を（非負）単関数という（1(A) は A の指示関数）。単関数の期待値は E\[s\] = a₁【ア】 + … + aₖP(Aₖ) と定める。非負の確率変数 X の期待値は

E\[X\] = sup{ E\[s\] : s は単関数で 0 ≤ s ≤ X }

で定義する（値 +∞ も許す）。これが E\[X\] = ∫ X dP と書かれるルベーグ積分である。リーマン積分が「定義域を細かく分ける」のに対し、ルベーグ積分は「値域を細かく分ける」点が要点である。

X を下から近似する単関数の列を具体的に作ろう。n = 1, 2, … に対し

```math
X_n = \sum_{k=0}^{n2^n - 1} \frac{k}{2^n}\, \mathbf{1}\Big\{\frac{k}{2^n} \le X < \frac{k+1}{2^n}\Big\} + n\, \mathbf{1}\{X \ge n\}
```

とおく。値域 \[0, n) を幅 2⁻ⁿ の区間に分け、各区間の左端の値で切り下げたものである。この Xₙ は n について 【イ】 であり（問1）、X(ω) < n を満たす ω では 0 ≤ X(ω) − Xₙ(ω) < 【ウ】 が成り立つ。よって各 ω で Xₙ(ω) → X(ω) となる。

(2) 単調収束定理：「0 ≤ X₁ ≤ X₂ ≤ … かつ Xₙ → X（各点）ならば E\[Xₙ\] → E\[X\]」が成り立つ。(1) の近似と組み合わせると、E\[X\] は E\[Xₙ\] の極限として計算でき、和や定数倍の線形性も単関数から極限で引き継がれる。

符号の変わる X に対しては X⁺ = max(X, 0)、X⁻ = 【エ】 とおき、X = X⁺ − X⁻、E\[X\] = E\[X⁺\] − E\[X⁻\] と定める。この差が意味をもつのは E\[X⁺\] と E\[X⁻\] の少なくとも一方が有限のときである。|X| = 【オ】 と書けるので、E\[|X|\] < ∞ のとき X は可積分であるという。

(3) 極限と期待値の順序交換は無条件には許されない。Ω = \[0, 1\] にルベーグ測度を入れ、fₙ = n·1((0, 1/n)) とする。各 ω で fₙ(ω) → 【カ】 だが、E\[fₙ\] = 【キ】 なので、lim E\[fₙ\] ≠ E\[lim fₙ\] である。この例は次の2定理の境目を示している。

- ファトゥの補題：fₙ ≥ 0 ならば E\[liminf fₙ\] ≤ liminf E\[fₙ\]（この例では 0 ≤ 【キ】 で等号は成り立たない）
- 優収束定理：fₙ → f（各点）かつ、すべての n で |fₙ| ≤ g となる可積分な g があれば E\[fₙ\] → E\[f\]

この例で g として最小にとれるのは g(ω) = supₙ fₙ(ω) であり、g(ω) はおよそ 1/ω に等しい。その期待値は ∫₀¹ (1/ω) dω と同程度で 【ク】 となるので、優収束定理の仮定が満たされない。確率の質量が小さな集合に「逃げて」いく状況では交換が破れる、と理解するとよい。

(4) X が値 x₁, x₂, … を確率 p₁, p₂, … でとる離散型なら E\[X\] = Σ xᵢpᵢ、密度 f をもつなら E\[X\] = ∫ x f(x) dx であった。測度論ではこの2つは X の分布 μ（問題Ⅲ）を用いた E\[X\] = ∫ℝ x μ(dx) に統一される。より一般に E\[g(X)\] = ∫ℝ g(x) μ(dx) が成り立つが、この等式は { ケ } と呼ばれる。

- ① 変数変換公式（像測度に関する積分の公式）
- ② フビニの定理
- ③ チェビシェフの不等式

問1　(1) の Xₙ について、Xₙ ≤ Xₙ₊₁ が各点で成り立つことを示せ。（ヒント：幅 2⁻ⁿ の区間を2等分すると幅 2⁻⁽ⁿ⁺¹⁾ の区間が2つできる。）

問2　X ≥ 0、a > 0 のとき、不等式 a·1{X ≥ a} ≤ X を用いて、マルコフの不等式 P(X ≥ a) ≤ E\[X\]/a を導け。

## 問題Ⅴ　独立性・収束概念・大数の法則

次の文章を読んで、【　】に適した式・数値を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 事象 A, B が独立であるとは P(A ∩ B) = 【イ】 が成り立つことをいう。測度論では独立性を σ-加法族の言葉で述べる。部分σ-加法族 G, H ⊂ F が独立であるとは、すべての A ∈ G, B ∈ H について P(A ∩ B) = 【イ】 が成り立つことである。確率変数 X に対し σ(X) = {X⁻¹(B) : B ∈ B(ℝ)} は X が生成する σ-加法族で、「X の値を見てわかる事象」の全体を表す。X と Y が独立であるとは σ(X) と σ(Y) が独立であることと定義する。

X, Y が独立で可積分なら E\[XY\] = 【ロ】 が成り立つ（指示関数で成立を確かめ、単関数、非負関数、一般の関数へと問題Ⅳの手順で拡張する）。分散については V(X + Y) = V(X) + V(Y) + 2【ハ】 であり、独立なら 【ハ】 = 0 となる。

(2) 確率変数列 X₁, X₂, … の X への収束には複数の意味がある。

- 概収束：P(limₙ Xₙ = X) = 1
- 確率収束：任意の ε > 0 で P(|Xₙ − X| > ε) → 0

概収束ならば確率収束する（問1）が、逆は成り立たない。反例として Ω = \[0, 1\]（ルベーグ測度）上で、n = 2^m + j（m = 0, 1, 2, …、0 ≤ j < 2^m）と一意に書いて、Xₙ を区間 \[j/2^m, (j+1)/2^m\] の指示関数とする（「タイプライター列」）。P(Xₙ ≠ 0) = 【ニ】 は n → ∞ で 0 に近づくので Xₙ は 0 に確率収束する。しかし各 m ごとに区間が \[0, 1\] を左から右へ一巡するため、どの ω についても Xₙ(ω) = 1 となる n が無限にあり、limsup Xₙ(ω) = 【ホ】 となる。よって Xₙ はどの点でも 0 に収束しない。

もっとも、確率収束する列からは必ず概収束する部分列を取り出せる。すなわち、確率収束するが概収束しない列でも、適当な部分列をとると { ヌ }。

- ① 必ず概収束する
- ② 概収束する部分列が存在しないこともある
- ③ 部分列をとっても確率収束すら保たれない

(3) 大数の弱法則。X₁, X₂, … は独立同分布で E\[Xᵢ\] = m、V(Xᵢ) = σ² < ∞ とし、Sₙ = X₁ + … + Xₙ とおく。(1) より V(Sₙ/n) = 【ヘ】 である。チェビシェフの不等式（問題Ⅳ問2のマルコフの不等式を (Sₙ/n − m)² に適用したもの）から

```math
P\Big(\Big|\frac{S_n}{n} - m\Big| \ge \varepsilon\Big) \le \text{【ト】} \longrightarrow 0
```

となり、Sₙ/n は m に確率収束する。

(4) 大数の強法則（4次モーメントを仮定した簡易版）。さらに E\[(Xᵢ − m)⁴\] = K < ∞ を仮定し、Yᵢ = Xᵢ − m とおく。(Y₁ + … + Yₙ)⁴ を展開すると、どれか1つの Yᵢ が1乗で現れる項は、独立性と E\[Yᵢ\] = 0 により期待値が 0 になる。残るのは Yᵢ⁴ の形の項と、i ≠ j についての Yᵢ²Yⱼ² の形の項だけなので

```math
E\big[(Y_1 + \cdots + Y_n)^4\big] = nK + \text{【チ】}
```

を得る。これに4乗についてのマルコフの不等式を使うと、P(|Sₙ/n − m| ≥ ε) は定数 C を用いて C/n^【リ】 以下で抑えられる。この級数は収束するので、問題Ⅱのボレル＝カンテリの第1補題により、確率1で |Sₙ/n − m| ≥ ε は有限回しか起こらない。ε = 1, 1/2, 1/3, … の可算個について同じ議論をすれば、Sₙ/n は m に概収束する。弱法則と強法則の差は、確率収束と概収束の差そのものである。

問1　Xₙ が X に概収束するならば確率収束することを示せ。（ヒント：事象 {|Xₙ − X| > ε} の上極限を考え、問題Ⅱの連続性を用いよ。）

問2　(2) のタイプライター列から、0 に概収束する部分列を1つ具体的に挙げ、概収束することを確かめよ。

## 問題Ⅵ　条件付き期待値

次の文章を読んで、【　】に適した式・語句を、{　} からは適切なものを一つ選びその番号を、それぞれ答えよ。また、問1・問2では指示にしたがって答えよ。

(1) 初等的な条件付き期待値 E\[X | B\] = E\[X·1(B)\] / P(B)（P(B) > 0）を、σ-加法族に関する形に書き直そう。Ω が互いに素な事象 B₁, …, Bₖ（各 P(Bᵢ) > 0）に分割されているとし、G = σ(B₁, …, Bₖ) とおく。G は「どの Bᵢ が起きたかだけがわかる」情報を表す。このとき

```math
E[X \mid \mathcal{G}](\omega) = \sum_{i=1}^{k} \frac{E[X \mathbf{1}_{B_i}]}{\text{【あ】}}\, \mathbf{1}_{B_i}(\omega)
```

と定める。これは数ではなく確率変数であり、各 Bᵢ の上で一定値をとるので 【い】 である。さらに、任意の G ∈ G は Bᵢ のいくつかの和なので、E\[ E\[X | G\]·1(G) \] = 【う】 が成り立つ。

(2) 一般の部分σ-加法族 G ⊂ F と可積分な X に対しては、(1) で見た2つの性質を定義として採用する。すなわち、確率変数 Y が

- (a) Y は G-可測である
- (b) すべての G ∈ G について E\[Y·1(G)\] = E\[X·1(G)\]

を満たすとき、Y を G に関する X の条件付き期待値といい、E\[X | G\] と書く。P(B) = 0 の事象で割り算をする必要がないことがこの定義の利点である。

存在はラドン＝ニコディムの定理から従う。X ≥ 0 のとき ν(G) = E\[X·1(G)\]（G ∈ G）は (Ω, G) 上の有限測度であり、P を G に制限したものに対して 【え】 である（P(G) = 0 ならば ν(G) = 0）。したがって密度 dν/dP が G-可測関数として存在し、それが E\[X | G\] である。一般の X は X⁺, X⁻ に分けて扱う。

一意性も確かめよう。Y と Y′ がともに (a)(b) を満たすとき、G = {Y > Y′} は G に属し、(b) より E\[(Y − Y′)·1(G)\] = 0 である。被積分関数は G 上で正なので P(Y > Y′) = 【お】 となり、同様に P(Y < Y′) = 【お】 である。つまり条件付き期待値は確率0の差を除いて一意に定まる。

(3) 定義 (a)(b) から次の性質が導かれる。

- (b) で G = Ω とすると E\[ E\[X | G\] \] = 【か】
- Z が G-可測で有界ならば E\[ZX | G\] = 【き】（「わかっている量は外に出せる」）
- X が G と独立ならば E\[X | G\] = 【く】（情報が役に立たない）
- H ⊂ G ならば E\[ E\[X | G\] | H \] = 【け】（粗い情報で平均し直すとよい：塔の性質）

さらに E\[X²\] < ∞ のとき、G-可測な二乗可積分確率変数全体 L²(Ω, G, P) は L²(Ω, F, P) の閉部分空間になり、E\[X | G\] はこの部分空間への { こ } とみなせる。

- ① 直交射影
- ② 等長写像
- ③ 微分作用素

問1　公正なサイコロを1回振り、出た目を X とする。G = σ({偶数の目}) とするとき、E\[X | G\] を求めよ。また E\[ E\[X | G\] \] = E\[X\] を確かめよ。

問2　E\[X²\] < ∞ とする。G-可測で E\[Z²\] < ∞ を満たす任意の Z に対し

```math
E\big[(X - Z)^2\big] \ge E\big[(X - E[X \mid \mathcal{G}])^2\big]
```

が成り立つことを示せ。（ヒント：X − Z = (X − E\[X | G\]) + (E\[X | G\] − Z) と分け、交差項が 0 になることを (3) の性質を用いて示す。）
